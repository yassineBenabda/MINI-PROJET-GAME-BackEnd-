![Java](https://img.shields.io/badge/Java-17-orange?logo=openjdk)

REST API for managing a video game catalog: games, genres, developers, platforms and libraries (*bibliothèques*). The API is secured with **Keycloak** (OAuth2 / JWT) and is designed to be consumed by an **Angular** front-end running on `http://localhost:4200`.

> Mini-project – *Projet Spring Boot pour la gestion des games*

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yassineBenabda/MINI-PROJET-GAME-BackEnd-.git
cd MINI-PROJET-GAME-BackEnd-
```

### 2. Configure the database

Edit `src/main/resources/application.properties` if your MySQL credentials differ:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/spring_DB?createDatabaseIfNotExist=true&useSSL=false&serverTimezone=UTC
spring.datasource.username=root
spring.datasource.password=root
spring.jpa.hibernate.ddl-auto=update
server.servlet.context-path=/games
```

The `spring_DB` database is created automatically and tables are generated by Hibernate.

### 3. Configure Keycloak

1. Start Keycloak on port **8090**.
2. Create a realm named **`yassine-realm`**.
3. Create a client named **`prod-app`**.
4. Add the client roles **`ADMIN`** and **`USER`** to `prod-app`, then assign them to your users.

The API validates JWTs issued by:

```properties
spring.security.oauth2.resourceserver.jwt.issuer-uri=http://localhost:8090/realms/yassine-realm
spring.security.oauth2.resourceserver.jwt.jwk-set-uri=http://localhost:8090/realms/yassine-realm/protocol/openid-connect/certs
```

Roles are read from `resource_access.prod-app.roles` in the token by `KeycloakRoleConverter`.

### 4. Run the application

```bash
# Linux / macOS
./mvnw spring-boot:run

# Windows
mvnw.cmd spring-boot:run
```

The API is available at **`http://localhost:8080/games`**.

## 🔐 Authentication

Every request must include a valid Keycloak access token:

```
Authorization: Bearer <access_token>
```

Example of obtaining a token (password grant, for testing — enable *Direct access grants* on the client):

```bash
curl -X POST http://localhost:8090/realms/yassine-realm/protocol/openid-connect/token \
  -d "client_id=prod-app" \
  -d "grant_type=password" \
  -d "username=<user>" \
  -d "password=<password>"
```

### Access rules

| Endpoint | Method | Roles |
|---|---|---|
| `/api/all` | GET | ADMIN, USER |
| `/api/getbyid/{id}` | GET | ADMIN, USER |
| `/api/addgame` | POST | ADMIN |
| `/api/updategame` | PUT | ADMIN |
| `/api/deletegame/{id}` | DELETE | ADMIN |
| Any other endpoint | * | Authenticated user |

## 📡 API Endpoints

All paths are prefixed with `/games`.

### Games — `/api`

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/all` | List all games |
| GET | `/api/getbyid/{id}` | Get a game by ID |
| POST | `/api/addgame` | Create a game |
| PUT | `/api/updategame` | Update a game |
| DELETE | `/api/deletegame/{id}` | Delete a game |
| GET | `/api/gamesgenre/{idGenre}` | List games of a genre |
| GET | `/api/auth` | Return the current authentication details |

### Genres — `/api/genre`

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/genre` | List all genres |
| GET | `/api/genre/{id}` | Get a genre by ID |
| POST | `/api/genre/addgenre` | Create a genre |
| PUT | `/api/genre/updategenre` | Update a genre |
| DELETE | `/api/genre/deletegenre/{id}` | Delete a genre by ID |

### Developers — `/api/developers`

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/developers/all` | List all developers |
| GET | `/api/developers/getbyid/{id}` | Get a developer by ID |
| POST | `/api/developers/adddeveloper` | Create a developer |
| PUT | `/api/developers/updatedeveloper` | Update a developer |
| DELETE | `/api/developers/deletedeveloper/{id}` | Delete a developer |

### Platforms — `/api/platforms`

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/platforms/all` | List all platforms |
| GET | `/api/platforms/getbyid/{id}` | Get a platform by ID |
| POST | `/api/platforms/addplatform` | Create a platform |
| PUT | `/api/platforms/updateplatform` | Update a platform |
| DELETE | `/api/platforms/deleteplatform/{id}` | Delete a platform |

### Libraries — `/api/biblio`

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/biblio/all` | List all libraries |
| GET | `/api/biblio/{id}` | Get a library by ID |
| POST | `/api/biblio/new` | Create a library |
| POST | `/api/biblio/{id}/games` | Add a game to a library |
| DELETE | `/api/biblio/{id}/games/{gameId}` | Remove a game from a library |

### Spring Data REST

| Endpoint | Description |
|---|---|
| `/rest` | Auto-generated CRUD for games (supports `?projection=nomGame`) |
| `/genre` | Auto-generated CRUD for genres |

## 🧪 Example Request

```bash
curl -X POST http://localhost:8080/games/api/addgame \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{
        "nomGame": "Elden Ring",
        "prixGame": 59.99,
        "datedeSortie": "2022-02-25",
        "email": "contact@example.com",
        "genre": { "idGenre": 1 },
        "developer": { "idDeveloper": 1 },
        "platforms": [ { "idPlatform": 1 }, { "idPlatform": 2 } ]
      }'
```
